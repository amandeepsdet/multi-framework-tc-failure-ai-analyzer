# Documentation

The documentation index for **aiqa** — the framework-agnostic AI failure
analysis SDK (install `multi-framework-tc-failure-ai-analyzer`, import `aiqa`).

New here? Start with the [README](../README.md), then run the
[canonical demo](../examples/sdk_demo.py) and browse a real
[sample output](../sample_output/).
