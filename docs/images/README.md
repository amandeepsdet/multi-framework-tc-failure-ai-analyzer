# README Images

This folder holds the screenshots and diagrams referenced by the top-level
[`README.md`](../../README.md). Drop the following PNG files here (recommended
width **≥ 1200px**, compressed) to light up the **Visual Overview** section.

| File | Shows |
|------|-------|
| `home.png` | Repository home / project banner |
| `architecture.png` | Layered architecture diagram (Adapters → FailureContext → Evidence → AI Engine → Reports → Output) |
| `playwright-run.png` | Playwright test execution in the terminal |
| `root-cause.png` | AI root-cause analysis report |
| `bug-report.png` | Generated tracker-ready bug report |
| `html-report.png` | Self-contained HTML report |
| `cli-assistant.png` | Interactive CLI assistant session |
| `pypi.png` | PyPI package page |
| `folder-structure.png` | Project folder structure |

## Tips

- Keep each image under ~500 KB (use [TinyPNG](https://tinypng.com) or `pngquant`).
- Use a consistent window theme and hide personal data before capturing.
- 16:9 or 16:10 framing renders best on GitHub.
